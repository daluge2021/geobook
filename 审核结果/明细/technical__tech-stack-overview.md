## 1. 核心答案提取

- 核心结论（≤100 字）：GEO 技术栈分四层——L1 基础设施（robots/sitemap/服务器/SSL）、L2 优化（Schema/llms.txt/实体/可引用性）、L3 监测（引用追踪/竞品）、L4 自动化（AgenticGEO）；必须自下而上建，12 周走完，按企业规模选方案。

- 可被直接回答的 5 个用户问题：
  1. 问题：GEO 技术栈的四层架构是什么？ → 答案：L1 基础设施 → L2 优化 → L3 监测 → L4 自动化；原则是"自下而上、不跳层"，跳层会导致上层失效（L1 没做 L2 无效、L2 没做 L3 无东西可优化、L3 没做 L4 缺数据基础）。【原文证据：第 1 节四层 ASCII 图 + 三条跳层后果列表；head FAQPage 第一问】
  2. 问题：四层分别有哪些工具、成本多少？ → 答案：L1 robots/sitemap 几乎零成本、HTTPS 用 Let's Encrypt 免费；L2 Schema 需 1–2 周开发、llms.txt 几乎零成本；L3 免费 Bing Webmaster Tools、入门付费 ¥300–500/月（Profound / Huiyuanliu）、企业级 BrightEdge / Yext 定制报价；L4 助理型（Miaozhi）→ 半自动（Profound Agent）→ 企业级（BrightEdge AutoGEO）。【原文证据：第 2 节 L1/L2/L3/L4 四张表格】
  3. 问题：GEO 技术栈要多久能落地？ → 答案：12 周——第 1–2 周 L1、3–6 周 L2、7–10 周 L3、11–12 周 L4 探索；每阶段附 checklist。【原文证据：第 3 节四小节 checklist；head FAQPage 第二问一致】
  4. 问题：不同规模企业各花多少钱？ → 答案：小团队（<50 内容）几乎零成本 + 人力；中型（50–200）约 ¥800–1,500/月工具费；大型（200+）约 ¥5,000–20,000+/月 工具与 Agent 费 + 专职团队。【原文证据：第 4 节三小节 "Total cost" 加粗句；head FAQPage 第三问一致】
  5. 问题：搭技术栈最容易犯什么错？ → 答案：三类——跳过 L1 直接做 L2–L4、一次买 4–5 个监测工具都用不好（建议一个工具用满 3 个月再换）、追自动化却连 robots/Schema 都没配好。【原文证据：第 5 节 Error 1–3】
