## 1. 核心答案提取
- 核心结论（≤100 字）：GEO 没有排名与展示数据、平台众多且模型月月更新，因此需要专用监测工具回答"是否被提及、被如何描述、哪个平台更喜欢我"；先建基线与监测清单，按周查、月析、把数据回灌下月策略，并避开三大误区。
- 可被直接回答的 5 个用户问题：
  1. 问题：GEO 为什么需要专用监测工具？ → 答案：三难题——AI 不是搜索引擎（无排名/展示数据、只知是否提及不知原因）、AI 平台太多需多平台同步、AI 模型月度更新导致引用策略频繁变化；工具解决"是否提及/如何描述/哪个平台更爱我"三问。【原文证据：§1 "Three Unavoidable Problems" 与 "Three Core Problems"】
  2. 问题：GEO 监测工具有哪些功能模块？ → 答案：六维矩阵——品牌提及监测(5星)、引用来源分析(5星)、竞品对比(4星)、描述准确性(4星)、情感分析(3星)、内容优化建议(3星)。【原文证据：§2 功能矩阵表】
  3. 问题：如何按预算选择 GEO 监测工具？ → 答案：起步用免费（Bing Webmaster + 手动测试）；有基础要系统监测选 Profound 或汇源流；已在用 SEMrush 选其 GEO 模块；大型企业选 BrightEdge 或 Yext；主攻中文市场选汇源流或妙智。【原文证据：§3 "How to Choose?" 对照表】
  4. 问题：GEO 监测的标准流程是什么？ → 答案：五步——建立基线扫描→配置监测清单（品牌词/5–10 核心主题/2–5 竞品）→每周快速检查→每月深度分析→把数据回灌为下月优化策略（例：CRM 定价主题引用份额 10%→3% 则补内容）。【原文证据：§4 Step 1–5】
  5. 问题：GEO 监测有哪些常见坑？ → 答案：三坑——只测一个 AI 平台（至少测 3 个）、只看是否提及不看描述准确性、追引用数不看转化（应与流量/线索/订单打通）。【原文证据：§5 Pitfall 1–3】

## 2. 准确性测试
- 核心概念与术语理解：GEO 监测三大问题、基线—清单—周检—月析的流程逻辑**准确且自洽**；"引用是曝光而非转化"的判断成立。
- 数字、日期、对象、条件引用：**价格表为高风险区**——Profound $99/月、SEMrush GEO 模块 $200/月、Yext $199/月、AthenaHQ"Custom"、汇源流 ¥500/月、妙智 ¥300/月，均标注"Starting Price (Reference)"但**无出处、无核验日期，全部待核实**；"Bing Webmaster Tools 免费含 AI 搜索分析数据"与"Google Search Console 提供 AI Overviews 引用数据"（实为 AI Overviews 展示/点击报告，非"citation data"）**表述有偏差**；"AI 模型每月更新"为泛化断言。
