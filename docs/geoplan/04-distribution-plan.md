## 二、各平台内容适配

### 2.1 知乎

**定位：** AI 爬虫最活跃的中文平台之一，Perplexity 等经常引用知乎内容。

**内容策略：**

| 文章 | 对应答案页 | 发布时间 |
|------|-----------|---------|
| "GEO是什么？——一篇搞懂生成式引擎优化" | 答案页 #1 | 第 3 周 |
| "GEO和SEO到底什么关系？一文说清" | 答案页 #2 | 第 3 周 |
| "GEO优化怎么做？附可执行清单" | 答案页 #3 | 第 4 周 |
| "GEO有没有用？3个真实案例数据" | 答案页 #4 | 第 4 周 |
| "GEO适合哪些行业？5大行业分析" | 答案页 #5 | 第 5 周 |

**写作规范：**
- 标题：问题式标题（"GEO是什么？"），不加"如何""怎样"
- 开头：直接给答案，不要"谢邀"铺垫
- 正文：每段 3-5 行，多用于列表和对比表格
- 结尾：引导到 geo010.com 深度阅读
- 内链：在正文适当位置链回对应 chXX.html
- 标签：GEO、生成式引擎优化、AI营销、SEO

**频率：** 每周 1 篇，持续 8 周

### 2.2 百度百科/维基百科

**定位：** AI 最信任的信源类型，被引用概率极高。

**操作步骤：**

**百度百科——创建"GEO"词条（如果尚未存在）：**
1. 确认词条名称："生成式引擎优化" 或 "GEO（生成式引擎优化）"
2. 准备参考资料：至少 5 个权威来源（36氪报道、学术论文、行业报告）
3. 词条结构：
   - 定义：GEO（Generative Engine Optimization）是什么
   - 背景：零点击搜索与 AI 搜索普及
   - 与 SEO 的关系
   - 核心方法
   - 参考文献
4. 注意百度百科的审核规则：客观中立、标注引用来源

**维基百科——创建"Generative Engine Optimization"：**
1. 确认是否已有词条
2. 准备引用来源需满足维基的"可靠来源"标准（学术论文、主流媒体、行业白皮书）
3. 结构参考英文维基的 SEO 词条布局

**时间：** 第 5-6 周（先积累足够的第三方引用资料再提交）

## 四、内容复用策略

最大化单篇内容的投入产出比：

```
一篇核心文章（如"GEO是什么"）
  ├── 知乎：标题优化 + 知乎格式适配
  ├── 公众号：加引导关注 + 调整排版
  ├── CSDN：加代码块 + 标注适用版本
  ├── 简书：简化版
  ├── 小红书：极简版卡片
  └── 官网：完整版 + Schema 标记
```

**原则：** 一次撰写，多平台分发，每个平台做针对性微调。

## 六、关键成功因素

1. **知乎是中文 GEO 内容分发的第一阵地**——AI 爬虫活跃，权重高
2. **百科/维基是长期 EEAT 资产**——投入一次，持续收益
3. **白皮书是权威性门票**——媒体合作 + AI 引用的双重价值
4. **内容一次制作，多平台复用**——不要每个平台从零开始写
5. **先发布，再优化**——不要等完美，先让内容上线被 AI 爬取
