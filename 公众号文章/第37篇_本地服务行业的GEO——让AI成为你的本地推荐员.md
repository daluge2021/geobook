## 一、本地服务AI搜索的"三个半径"


### 半径一：位置半径

用户在AI上搜索本地服务时，通常有三个级别的位置精度：

| 精度级别 | 问题示例 | AI的回答方式 |
|---------|---------|------------|
| **漫半径** | "附近有什么好吃的？" | AI根据用户当前位置推荐 |
| **区域半径** | "海淀区有推荐的健身房吗？" | AI根据特定区域推荐 |
| **商圈半径** | "望京SOHO附近有什么咖啡店？" | AI根据特定地标推荐 |

**GEO启示：** 你的品牌信息需要在所有三个"位置精度"上都有存在感。


### 半径二：品类半径

用户搜索本地服务时的品类精度也不同：

- **泛品类**："附近有什么好吃的"——用户不知道自己想吃什么
- **中品类**："附近有什么火锅店"——用户知道想吃火锅
- **细品类**："附近有什么重庆老火锅"——用户的意图非常明确

**GEO启示：** 你的内容需要覆盖"泛-中-细"三个品类层级。


### 半径三：决策半径

用户到AI搜索时的"决策进度"不同：

- **探索阶段**："周末带孩子去哪玩"——用户还没定
- **初筛阶段**："望京适合亲子的餐厅推荐"——初步锁定区域和品类
- **确认阶段**："望京XX餐厅怎么样，带孩子去合适吗"——用户已经有了候选

**GEO启示：** 品牌需要在所有"决策阶段"都有内容被AI引用。

## 二、本地服务品牌GEO的"五大基础设施"


### 1. 本地化百科/地图信息

**这是本地服务GEO最重要、最不能缺的基础设施。**

- **百度地图/高德地图**：完善门店信息（名称、地址、电话、营业时间、照片）
- **大众点评/美团**：积极管理评价，回复用户评论
- **百度百科**：如果有连锁规模，建立品牌百科词条

**AI的逻辑：** 当用户问"附近XX餐厅"时，AI会调用地图和点评平台的API。如果你的品牌在地图上的信息完整、在大众点评上的评分高，AI会优先推荐你。


### 2. 本地化关键词内容

为你的每个门店/服务区域创建独立的本地化内容页面。

**一个门店/区域一个页面**——不要把所有门店的信息挤在一个页面。

**单个门店页面的必备信息：**
- 门店名称+地址+电话（LocalBusiness Schema标记）
- 营业时间
- 服务项目
- 价格区间
- 门店照片
- 交通指引
- 用户评价摘要


### 3. 用户评价的"结构化"

本地服务品牌，用户评价是最有力的GEO信号。

**怎么让AI"看到"你的评价？**
- 在官网展示精选评价（用Review Schema标记）
- 在大众点评/Google Maps上积极管理评价
- 在社交平台上鼓励用户@你的品牌

**AI会"收集"你在所有平台上的评价，汇总成对你的"口碑评分"。** 如果一个品牌在5个平台上都有4.5分的评价，AI推荐时的信心远高于"只有一个平台有5分"（可能是刷的）。


### 4. 本地化互链网络

**本地化互链网络**——和本地的其他商家、机构、社区建立链接关系。

- 加入本地商会的网站会员名录
- 和本地社区网站互换链接
- 被本地媒体报道（"XX社区新开了一家……"）

**AI的逻辑：** 如果本地商会、本地社区的网站都在"推荐"你，你在"本地"的权威性就更高。


### 5. 多门店Schema部署

如果你有连锁门店，用LocalBusiness Schema标记每个门店。

```json
{
  "@type": "LocalBusiness",
  "name": "XX火锅·望京店",
  "image": "https://example.com/wangjing.jpg",
  "address": {
    "@type": "PostalAddress",
    "streetAddress": "望京SOHO T1-101",
    "addressLocality": "北京",
    "addressRegion": "朝阳区"
  },
  "telephone": "010-12345678",
  "openingHours": "Mo-Su 11:00-22:00",
  "aggregateRating": {
    "@type": "AggregateRating",
    "ratingValue": "4.6",
    "reviewCount": "328"
  }
}
```

每个门店独立ID、独立URL、独立Schema标记。

## 三、本地服务GEO的内容策略


### 必选内容类型

**1. "最佳XX"榜单内容**
> "2026年XXX区TOP10火锅店推荐"
> "XXX区最适合约会的餐厅"

**AI引用逻辑：** 你的榜单如果被AI引用，同时推荐了其他品牌的店——不要担心"帮别人做广告"。AI在引用你的榜单时，你的品牌也会被用户看到。

**2. "本地指南"内容**
> "周末在XXX区怎么玩——本地人推荐路线"
> "XXX区咖啡店地图"

这类内容覆盖的是"探索阶段"的用户——他们虽然还不知道你的具体品牌，但已经开始在AI上了解本地的信息了。

**3. "场景化推荐"内容**
> "带父母聚餐去哪里——XXX区适合家庭的餐厅推荐"
> "一个人去吃的火锅店推荐"

AI最喜欢引用"场景化"的内容——因为它可以直接把内容嵌入到对应用户场景的回答中。


### 本地化内容的"公式"

> **"位置 + 品类 + 场景 + 人群 = 高匹配的本地化GEO内容"**

| 位置 | 品类 | 场景 | 人群 | 内容标题 |
|------|------|------|------|---------|
| 望京 | 火锅 | 聚餐 | 朋友 | "望京朋友聚餐火锅店推荐" |
| 海淀 | 咖啡 | 办公 | 程序员 | "海淀区适合办公的咖啡店" |
| 西单 | 美发 | 约会 | 女生 | "西单适合约会前做造型的理发店" |

## 四、本地服务GEO的"口碑"放大效应


### 口碑在本地GEO中的特殊地位

在本地服务行业，口碑的力量被AI"超级放大"。

**传统模式下：** 10个朋友说"那家店不错"→ 你知道了
**AI模式下：** AI收集了200条评价 → AI得出"这家店评分4.6，推荐" → 你没见过那10个朋友，但AI替你问了"所有人"

一次好的消费体验 + 一个评价 = 被AI"永久记住"的口碑信号。
一次差的消费体验 + 一个差评 = 同理。


### 如何主动管理口碑GEO？

1. **设置评价"触发点"**：在消费完成后，引导用户在多个平台留下评价
2. **及时处理差评**：公开回复差评，展示你解决问题的态度。AI也会"看到"你的回应
3. **鼓励"带图评价"**：带图的评价被AI引用的权重高于纯文字评价
4. **维护多个平台**：不只在单一平台上评价高，在3个以上的平台上都要有较好的评价

---

本地服务品牌的GEO逻辑和全国性品牌完全不同——

**全国性品牌比拼的是"权威性"和"内容深度"；本地品牌比拼的是"存在感"和"口碑"。**

对于本地服务品牌来说，GEO最高效的路径是：
1. 完善地图/点评上的基础信息（基础设施）
2. 用本地化内容覆盖用户的各种搜索场景（内容）
3. 通过优质体验驱动口碑（评价）
4. 让AI在用户搜索"附近XX"时，自动把你放在推荐列表的前列

**每个本地品牌都有机会成为AI眼中的"附近最佳"——只要你做好了被AI"发现"和"信任"的准备。**
